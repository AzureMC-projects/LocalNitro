# LocalNitro

A local-only Vencord user plugin for Windows Discord clients.

## Scope

LocalNitro adds client-side cosmetic previews and quality-of-life features. It does not grant Discord Nitro, bypass server-side entitlement checks, alter upload limits, or represent local cosmetics as server-approved account features.

## Development

This repository is intended to be developed as a private Vencord user plugin. Follow the current Vencord build instructions and keep the plugin in `src/userplugins/localnitro` in your Vencord checkout.

## Planned features

- Local Nitro-style settings and feature flags
- Local profile/banner/avatar decoration previews
- Cosmetic theme and media-preview enhancements
- Clear fallbacks for features that require server-side entitlements

## Disclaimer

Unofficial community project; not affiliated with Discord or Vencord. Client modifications may carry account or stability risks.
