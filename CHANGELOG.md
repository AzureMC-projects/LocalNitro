# Changelog

Notable project changes are documented here. This project is still an early development build; no release has been marked stable.

## Unreleased

### Added
- Live accent palettes: Violet, Ocean, Rose, and Mint.
- Optional local-only client notice and softer-corner styling.
- Local sample profile/banner/avatar concept preview with fixed demo data.
- Opt-in HTTPS image/GIF URL preview with a warning that the remote host receives a request.
- Repository contribution and security guidance, issue templates, pull request checklist, project mark, and basic repository hygiene workflow.

### Notes
- The plugin has not yet been verified by a successful build against a current Vencord checkout.
- Discord's internal CSS selectors may change without notice.
- No Nitro entitlement, upload limit, permission, or server-side check is bypassed.
